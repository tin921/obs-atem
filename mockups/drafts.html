ATEM PiP panel — earlier drafts

← Current layout (chosen: revised B)

Three candidate layouts for the ATEM PiP dock. Each page shows the panel at dock size (resize it with the Dock width slider), the SDK calls it would send, and buttons that simulate changes made elsewhere — to check the panel follows the ATEM without fighting the operator. Nothing here connects to a switcher. Value ranges match pip-dock.cpp and still need checking on the real ATEM Mini.

A — Classic

Grouped sections with a slider and number box for every value. Mirrors the current Qt skeleton. Complete and predictable; the tallest layout.

B — Direct manipulation

Drag the PiP box on the preview to move, resize and crop it. ATEM-style bus buttons for sources, compact number grid for exact values.
