ATEM PiP panel — current layout

Revised design B. Camera buttons pick the main picture and the PiP (press the lit PiP button to take PiP off air). Drag the box on the preview to move it, drag its corner to resize, or type exact numbers — the mouse wheel steps a focused number field. Crop is typed only and switches on by itself when any edge is non-zero. Save the whole setup to one of the seven buttons on the left and recall it with one click.

How this maps to the panel, and open questions
  • The top row is MAIN, the second row is PIP (no row labels; tooltips say which).
  • Camera and preset buttons: orange border on hover and when active. Each camera's name is set in ⚙; on the buttons it shows while no picture is set, or always with "Show names on camera buttons".
  • MAIN buttons: exactly one lit, the program camera. Pressing the lit one does nothing (the program can't show "nothing"). If the program is not a camera (e.g. Black, bars), none are lit.
  • PIP buttons: pressing an unlit one sets it as the PiP source and puts the PiP on air; pressing the lit one takes the PiP off air. No separate on-air button.
  • Preset buttons: store main camera, PiP camera, PiP on/off, X, Y, size and crop. The thumbnail is a picture of the preview at save time (drawn from the camera pictures). In OBS it could instead be a real frame of the ATEM video — see question 1.
  • ⚙ settings: a name, colour and picture per camera; the colour fills in where there is no picture; the picture is used on the camera buttons, in the preview and therefore in the preset thumbnails. In the plugin these would be PNG file paths saved in the plugin settings; here they are kept in this browser only.
  • Open question — preset thumbnails: picture composed from the camera PNGs (as here), or a real frame grabbed from the ATEM's video source in OBS?
